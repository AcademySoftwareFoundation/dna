# About

DNA (Dailies Note Assistant) is an
[Academy Software Foundation](https://www.aswf.io/) project. It aims to explore how large-language-model-assisted transcription and summarization can meaningfully enhance the VFX dailies note-taking process, prioritizing practical utility and thoughtful support for production professionals.

For more about our intentions with the DNA app, please read the [Introduction](/docs) in our Frontend docs.

This site hosts two kinds of documentation:

- **[Frontend](/docs)** — hand-written guides authored in MDX for the production ready app version of the tool.
- **[Backend API](/api)** — HTTP reference for developers looking to host or build on top of DNA.

The API reference is generated from the FastAPI application in
[`AcademySoftwareFoundation/dna`](https://github.com/AcademySoftwareFoundation/dna/tree/main/backend),
so it tracks the server's actual routes and models rather than a hand-maintained
copy.
