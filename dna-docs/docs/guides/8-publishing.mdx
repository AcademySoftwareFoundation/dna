## Publishing Notes

The Publish Notes dialog collects your notes for review before sending them to production tracking. Each note appears alongside its version for a final read, and images attached to a note are uploaded with it. When the user continues, a summary reports what happened, including notes published or republished, images attached, and statuses updated. Anything that failed is listed in the same summary.

## Publishing Statuses

Alongside each note you can pick a new status for the version from a dropdown, which is applied in production tracking as part of the same publish. Leave it unchanged to publish the note without touching the status.

## Publishing Transcriptions

Raw transcript segments can be included with a publish, so the full record of what was said stays attached to the version. In the dialog, expand or collapse the transcript on each note to decide whether it goes along.
