## Setting a Version to In-Review

"In-review" marks the version currently on screen in your dailies session, so notes and transcript segments land on the right version. Hover a version card and use the Set In Review control, press the Set In Review keyboard shortcut, or let the [RV integration](./7-rv-integration.mdx) set it automatically. A version indicator shows which version is currently in review, so you always know where new notes will land.

## Pinning

Pinning allows users to continue to pipe transcript segments directly to a version regardless of changes triggered by In-Review integrations. For example, if using RV, moving on to the next version will not change which version is In-Review, if another version is pinned. In a [session](./12-sessions.mdx), that same pin also keeps in review from moving to another playlist.
