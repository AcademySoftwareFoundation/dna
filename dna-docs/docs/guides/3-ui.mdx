## Side Bar

The sidebar lists every version in the current playlist. Click a version card to select it, search with the field at the top, or collapse the sidebar to give notes more room. You can also step through the playlist with the Next Version and Previous Version keyboard shortcuts.

<Figure
  src="img/3-ui/sidebar.png"

  alt="DNA sidebar"
  caption="Image shows the DNA sidebar."
/>

## Notes Box

Each version gets its own notes box, a rich text editor where you (and the AI) draft notes before publishing. Notes support markdown formatting, and typing @ opens a mention list so you can tag people and link shots, assets, and versions right inside the note.

<Figure
  src="img/3-ui/notes-box.png"
  width="100%"
  alt="DNA user interface"
  caption="Image shows the DNA user interface."
/>

## Search

Use the search field in the sidebar to filter versions in the playlist, or the expandable search in the transcript panel to jump between matches. The Focus Search shortcut takes you straight to the version search.

## Production Tracking Tab

With the DNA tab sync Chrome extension installed, DNA keeps a production-tracking browser tab in step with your selected version. Use the "PT tab" button in the version header, or let it follow automatically as versions change. In settings you can choose which page the tab opens: the version's detail page, or the linked shot or asset.
