# How-to for User Guides

Hand-written guides for the DNA app, authored as regular Docusaurus MDX.

These pages live in `docs/` and are served under `/docs`. They are completely
separate from the [Deployment](/deployment) docs, which live in `deployment/`
and are served under `/deployment`, and from the [Backend API reference](/api),
which is generated from an OpenAPI specification and served under `/api`.

## How the two sections differ

| | User guides | Deployment docs | Backend API docs |
| --- | --- | --- | --- |
| Route | `/docs` | `/deployment` | `/api` |
| Source | `docs/**/*.mdx`, written by hand | `deployment/**/*.mdx`, written by hand | `openapi/backend.yaml`, generated |
| Sidebar | `sidebars.ts` | `sidebarsDeployment.ts` | `sidebarsApi.ts` + generated slice |
| Doc component | Docusaurus default | Docusaurus default | `@theme/ApiItem` |

Because they are independent `plugin-content-docs` instances, MDX features
here are unaffected by the OpenAPI theme, and regenerating the API reference
never touches these files.

## Writing a page

Add an `.mdx` file anywhere under `docs/`. The sidebar is autogenerated from the
folder structure, so a new file shows up without any config change:

```mdx title="docs/guides/my-page.mdx"
---
sidebar_position: 2
---

# My Page

Ordinary MDX. Import components, use admonitions, whatever you need.
```

:::tip
Use `_category_.json` inside a folder to control its sidebar label and position.
:::
