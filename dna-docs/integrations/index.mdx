## Building your own

The RV package has no special access to DNA. It sets the version in review with one HTTP request, and any player that can send that request can do the same.

- [Set or clear session in-review](/api/reference/update-session-in-review-sessions-session-id-in-review-put) is the request: a `PUT` to the DNA session with the playlist ID as `in_review_playlist_id` and the version ID as `in_review_version_id`. DNA answers `400` if the version isn't on that playlist, and `409` while the version in review is pinned.
- The session comes from DNA's desktop sign-in page, which hands it to the player with the show and playlist. A player that only knows a playlist can get its session from [Ensure an implicit DNA session for a playlist](/api/reference/ensure-session-for-playlist-sessions-ensure-for-playlist-post).
- [Real-time](/api/realtime) covers the event stream DNA uses to tell every open session about the change.
- [Authentication](/api/authentication) covers the bearer token the request needs.
