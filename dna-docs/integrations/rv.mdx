How to install the DNA package for RV, switch it on for your studio, and tell it where to find version IDs. For the day-to-day steps once it is installed, see the [RV Integration user guide](/docs/7-rv-integration).

The package tells DNA which version is on screen in RV, so the version [in review](/docs/4-in-reivew) changes as a reviewer steps through the playlist. It works with both RV and OpenRV.

<LiveRvSyncDemo caption="Each time the source changes in RV, the package sends DNA one request and DNA moves the version in review to match." />

## What You Need

- RV or OpenRV built with Qt 6 and PySide6. The package has been tested with RV 2026.0.1 and OpenRV 4.0.2.
- The address of your studio's DNA web app, for example `https://dna.example.com`.
- **Enable In Review** switched on in DNA's [settings](/docs/10-settings). It is already on if you use transcription.

## Installing the Package

The package lives in the [rv-dna repository](https://github.com/jspada200/rv-dna). On macOS, download or clone the repository and run this from inside it:

```sh
make install
```

This builds `dna-<version>.rvpkg` and installs it into `~/Library/Application Support/RV`. If RV is not at `/Applications/RV.app`, point the install at it:

```sh
make install RV_APP="/Applications/RV 2.app"
```

On Linux or Windows, run `make package` to build the `.rvpkg` file into `dist/`, then add it in RV with **Add Packages...** on the Packages tab described below.

## Loading It in RV

The package is optional, so RV installs it switched off. Open **RV > Preferences > Packages**, tick **Load** next to **DNA**, then restart RV.

<Figure
  src="img/7-rv-integration/rv-packages.png"
  alt="RV's Preferences window on the Packages tab, with Installed and Load both ticked for the DNA package."
  caption="The DNA package in RV's Packages preferences, with Load ticked."
/>

After the restart, RV has a **DNA** menu in its menu bar.

To switch the package on for everyone who shares an RV support area, run `rvpkg -optin` on the installed `dna-<version>.rvpkg` instead of asking each person to tick Load.

## How RV Finds the Version

Whenever the source on screen changes, RV works out which version it is and sets that version in review in DNA. A few rules decide whether the change reaches DNA:

- **The version has to be on the playlist.** RV only sets versions from the playlist chosen at sign-in. Anything else loaded in RV is left alone.
- **A pinned version stays put.** If someone has [pinned](/docs/4-in-reivew#pinning) the version in review, moving on in RV does not change it until it is unpinned.
- **RV has to know which version a source is.** Sources it cannot identify are skipped.

RV looks for the version ID in the places listed in `version_id_paths.json` in the package, in order. The defaults are:

1. Media served by Flow Production Tracking, whose file URL contains `/file_serve/version/<id>/`.
2. A `version_id` metadata field on the source.
3. A `version_id` property on the source.

Studios that track version IDs differently can edit that file before building the package.

## The DNA Menu

| Menu item | What it does |
| --- | --- |
| **Signed in as ...** / **Not signed in** | Shows who is signed in and which playlist RV is driving. |
| **Sign In...** / **Sign Out** | Opens DNA's sign-in window, or forgets the saved sign-in. |
| **Switch show/playlist...** | Reopens the project and playlist picker without signing out. |
| **Set DNA URL...** | Changes the DNA web app address. Changing it signs you out. |
| **Debug mode** | Shows each request to DNA, and DNA's answer, as a message over RV's viewer. |

## Troubleshooting

**There is no DNA menu.** Check that **Load** is ticked for DNA in **RV > Preferences > Packages**, then restart RV.

**The sign-in window shows an error.** Check the address with **DNA > Set DNA URL...**. It should be the same address DNA opens at in a browser.

**DNA does not follow RV.** Work through these in order:

1. In DNA, check that **Follow In Review** is on.
2. In RV, check that the playlist named in the DNA menu is the one open in DNA.
3. Check whether the version in review is pinned.
4. Turn on **DNA > Debug mode** and change source in RV. RV shows the request it sent and what DNA answered, or says that it found no version ID for the source.

**Syncing stops after about an hour.** With Google sign-in, the sign-in expires after about an hour and RV does not renew it. Choose **DNA > Sign In...** again.

## Known Limits

- Signing in with Google from inside RV has not been tested yet, and Google may refuse to sign in from an embedded window.
- RV stores the sign-in in its preferences as plain text. On shared workstations, ask people to choose **DNA > Sign Out** when they finish.
- The playlist is chosen in DNA's sign-in window. RV does not work it out from the session it has loaded.

## Other Review Players

RV is the first player built this way, not a special case. See [Building your own](/integrations#building-your-own) for the request any player can send.
