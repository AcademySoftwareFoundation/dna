The [User Guides](/docs) are hand-written guides for the DNA app, authored as
regular Docusaurus MDX. They live in `docs/` and are served under `/docs`.

## How the sections differ

The site has five sections. The Backend API reference is generated, and the
other four are written by hand.

| Section | Route | Source | Sidebar |
| --- | --- | --- | --- |
| User Guides | `/docs` | `docs/**/*.mdx` | `sidebars.ts` |
| Frontend | `/frontend` | `frontend/**/*.mdx` | `sidebarsFrontend.ts` |
| Deployment | `/deployment` | `deployment/**/*.mdx` | `sidebarsDeployment.ts` |
| Contributing | `/contributing` | `contributing/**/*.mdx` | `sidebarsContributing.ts` |
| Backend API | `/api` | `openapi/backend.yaml`, generated | `sidebarsApi.ts` + generated slice |

Because they are independent `plugin-content-docs` instances, MDX features in
the hand-written sections are unaffected by the OpenAPI theme, and regenerating
the API reference never touches their files.

## Writing a page

Add an `.mdx` file anywhere under `docs/`. The sidebar is autogenerated from the
folder structure, so a new file shows up without any config change:

```mdx title="docs/guides/my-page.mdx"
---
sidebar_position: 2
---

# My Page

Ordinary MDX. Import components, use admonitions, whatever you need.
```

:::tip
Use `_category_.json` inside a folder to control its sidebar label and position.
:::
